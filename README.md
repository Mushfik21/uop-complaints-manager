# UoP Complaints Manager

SeTaP (M30819) group project, University of Portsmouth, 2026/27.

## What we're building

A system for reporting complaints about courses at UoP, built to be better than the current one.

- **Students** can report complaints, keep track of them and check how they were resolved.
- **Course Leaders** can give input at each stage, write an action plan and delegate tasks from it to other stakeholders.
